---
name: Never ask — always fix everything completely
description: When presenting bug analysis, never ask "how to proceed" — always fix all issues found, completely, without asking.
type: feedback
---

When a bug is found and analyzed, NEVER ask the user "how to proceed" or "what to fix first" or "do you want me to fix X?".

**Why:** The answer is ALWAYS "fix everything completely." The user has stated this explicitly and considers asking a waste of time.

**How to apply:** After discovery/analysis phase, immediately proceed to fix ALL identified issues — no confirmation, no prioritization questions, no "which one first?", no "which approach do you prefer?". Always choose the most professional, complete, and thorough approach and execute immediately. This applies to ALL decisions: architecture choices, fix strategies, test coverage level, implementation options.
